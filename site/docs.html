Synapse docs

Everything you need to get Synapse running and working for you: from installing it to adding your API key, working with your Bots, and fixing things when they go wrong.

Getting started

Requirements

  • A Mac with Apple silicon (M1 or later), on macOS 14 or later.
  • About 8 GB of free disk space.
  • OrbStack, which runs the Linux computer your Bots work in. It's free for personal use.
  • An Anthropic API key from the Anthropic Console, with some credit on the account.
  • An internet connection for setup and while your Bots work.

Install

  1. Install OrbStack and open it once.
  2. Download Synapse (the .dmg file), open it, and drag Synapse onto Applications.
  3. Open Synapse from Applications. The first time, macOS stops it, because Synapse isn't notarized by Apple yet:
    • Right-click Synapse and choose Open, then Open again, or
    • on newer macOS versions, go to System Settings → Privacy & Security, scroll down and click Open Anyway next to Synapse.
    You only need to do this once.

First run

  1. The Bots' computer. Synapse starts OrbStack and builds a small Linux computer for your Bots. It downloads about 1 GB, so give it a few minutes. If it stops partway, press Retry.
  2. Input API Key. Paste your Anthropic API key. Synapse checks it and tells you plainly if something's wrong.
  3. A quick tour, then pick the tools you use every day and meet your first Bot: start from a suggested one or create your own.

When you first use a feature that needs it, macOS asks for access to the microphone, screen recording or accessibility. Synapse never asks up front.

Your API key

Getting a key

  1. Sign in to the Anthropic Console and add some credit under Billing.
  2. Open API Keys, create a key and copy it. It starts with sk-ant-.

Adding, changing or removing it

Open Settings → Account. You'll see your saved key with most of it hidden.

  • Change it: paste the new key and click Replace key.
  • Check it: click Check to see whether the key works, which Claude models it can use, and whether web search is on for your account.
  • Remove it: click Remove. Your Bots stop until you add a key again.

Synapse only works with an Anthropic API key. Signing in with a Claude subscription or a Claude Code login isn't supported.

Using Synapse

Bots

A Bot is a teammate with its own name, look, instructions, memory and skills. Add Bots from the sidebar. Each one keeps its own memory and works on the shared Bots' computer, so several can work at once and hand tasks to each other.

To change what a Bot does, how it looks or what it's allowed to do, open its settings from its chat.

Working with Bots

Talk to a Bot the way you'd brief a colleague: say what you want done and any constraints. Bots break the work into steps, and you can see each step as it happens: files read, commands run, pages visited. They'll send files back to you in the chat, and ask before doing anything risky.

You can add files to a message, and point a Bot at the accounts and tools you connected during setup.

Code

Point a Bot at a repository and describe the change. It works on its own branch in a separate copy of the repo, so it never touches your working files. It runs the tests, then hands back the branch or opens a pull request for you to review.

Voice calls

Press Call in a Bot's chat to talk to it. Your speech is transcribed on your Mac, and the Bot's voice is generated on your Mac as well. Approvals can pop up during a call, so you can say yes or no without leaving it. You can change voices and sound options in Settings → Voice.

Your Mac and approvals

Bots can use your Mac's apps and screen and run commands in a sandbox. Anything risky, such as sending a message on your behalf, stops and asks first:

Allow onceDo it this one time.
Always allowDon't ask again for this exact kind of action.
DenyDon't do it. The Bot is told and carries on without it.

Mac permissions and the Bots' computer live in Settings → Computer.

Schedules

Bots can do work on a schedule, like a morning inbox brief on weekdays, or when something happens, like an invoice arriving. They tell you what they found. Manage these in Settings → Schedules.

Managing Synapse

Spending and budgets

Your Bots use your API key, so Anthropic bills you for what they use. Synapse meters every model call. Settings → Account shows spend per Bot by day, week and month.

Set a weekly or monthly budget there too. When a Bot reaches it, it pauses or asks you before spending more.

Settings at a glance

AccountYour API key, usage and budgets.
VoiceVoices and call sounds.

SchedulesScheduled and triggered work.
SystemUpdates, setup and repair of the Bots' computer, backups, diagnostics.

Updates

Synapse checks for new versions itself. You can also check in Settings → System → Updates. With Automatic Updates on (the default), it downloads a new version and asks you to restart. With it off, the new version waits in Settings → System → Updates until you download it. Before installing an update, Synapse verifies it was signed with the Synapse release key and signed by the same developer as the app you have. If either check fails, it refuses the update.

Backups

Settings → System → Backups saves your Bots, their memory and settings, and restores them later.

Privacy and your data

  • No Synapse account or server. Synapse talks straight to Anthropic with your key. Nothing goes through us.
  • Your data stays on your Mac, in ~/Library/Application Support/Synapse, and in the Bots' computer (an OrbStack machine called box).
  • Secrets are encrypted with a key kept in the app's own data folder. Bots' sandboxed commands can't read it.
  • Logs are in ~/Library/Logs/Synapse and never leave your Mac unless you send them.

Help

Troubleshooting

macOS says it can't open Synapse

Right-click Synapse → Open, or System Settings → Privacy & Security → Open Anyway. See Install.

Setting up the Bots' computer failed

Check OrbStack is installed and running, and that you have a connection and at least 8 GB free, then press Retry. If it keeps failing, use Settings → System → Setup to repair it.

My API key doesn't work

Use Check in Settings → Account. It tells you whether the key is wrong, the account is out of credit, or you've hit a rate limit. Make sure the key starts with sk-ant- and has credit in the Anthropic Console.

Synapse in two macOS accounts on the same Mac

Supported from version 0.1.1. Each account has its own Bots' computer and its own connection to it. If Synapse ever reaches another account's Bots' computer instead, it tells you.

Something else

Open an issue with what you did and what happened. Settings → System → Diagnostics shows recent errors, and the logs are in ~/Library/Logs/Synapse.

Uninstall

  1. Quit Synapse and drag it from Applications to the Trash.
  2. To remove your data too, delete ~/Library/Application Support/Synapse and ~/Library/Logs/Synapse.
  3. To remove the Bots' computer, open OrbStack and delete the machine called box. Only do this if you don't use a machine with that name for anything else.
