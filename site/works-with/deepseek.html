Synapse with DeepSeek

Run your Bots on DeepSeek models with your own DeepSeek API key.

What works

  • Models: DeepSeek V4.1 Flash and DeepSeek V4 Pro.
  • Chat, tools and replies, through the same approvals as every Bot.
  • Voice calls.
  • Subagents, on the same model.
  • Computer and browser helpers, on the same model. They work from text reads of the screen and page instead of screenshots, as Experimental.
  • A context window of 1 million tokens.
  • Coding agents and Engineering mode, on the same model, through the same approvals.

Every model starts as Not checked. A badge is earned by measurement, not given. See how badges are earned.

Not yet

  • Images. DeepSeek's models don't take them.
  • Web search of its own. A DeepSeek Bot borrows search from OpenAI, Gemini or OpenRouter if you've set one up; otherwise it has none.

Privacy

  • Consent first. Nothing goes to DeepSeek until you allow it once. The consent says what is sent: the conversation, tool results, files the Bot reads, safety-check inputs, memory notes and call transcripts. DeepSeek's own terms apply.
  • Your key stays on your Mac. It is encrypted, and only Synapse's own proxy adds it to a request. Your Bots never see it. Each call gets a one-time token, and the key is removed from anything that comes back.
  • The same safety gate. Every action goes through Synapse's fixed rules and approvals, whatever the model. The safety reviewer runs on Claude when you've saved an Anthropic key, and otherwise on the provider you set up. You can pick another model for it in Settings → Rules → Safety reviewer. A reviewer on a model other than Claude asks you first until it passes the safety check.

Set up

  1. Create an API key on the DeepSeek platform, with some credit on the account.
  2. In Synapse, open Settings → Account → Model providers. Click Allow next to DeepSeek, read what it sends, and allow it.
  3. Paste the key, click Save, then Test key.
  4. Open a Bot's settings and pick a DeepSeek model.

You can also start with DeepSeek: pick it in the key step when you first open Synapse, allow it, and paste the key. It's tested before it's saved, and no Anthropic key is needed.
