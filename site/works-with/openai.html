Synapse with OpenAI

Run your Bots on OpenAI models with your own OpenAI API key.

A ChatGPT plan doesn't cover this. Synapse uses an API key from the OpenAI platform, which OpenAI bills separately.

What works

  • Models: GPT-6 Astra, GPT-6.1 Sol and GPT-6 Luna.
  • Chat, tools and replies, through the same approvals as every Bot.
  • Web search, through OpenAI's own search tool.
  • Images, in a message and from a tool.
  • Voice calls.
  • Subagents, on the same model.
  • A context window of about 1 million tokens.

Every model starts as Not checked. A badge is earned by measurement, not given. See how badges are earned.

Not yet

  • Coding agents. They run on Claude, so they need an Anthropic key.
  • Computer and browser helpers. They still run on Claude, so they need an Anthropic key.

Cost

OpenAI bills your own key. Synapse meters every call and counts it against your spend budget. When the budget is reached, the model isn't called.

  • The model picker shows what 100 turns like your Bot's recent ones would cost on each model.

Privacy

  • Consent first. Nothing goes to OpenAI until you allow it once. The consent says what is sent: the conversation, tool results, files the Bot reads, safety-check inputs, memory notes and call transcripts. OpenAI's own terms apply.
  • Your key stays on your Mac. It is encrypted, and only Synapse's own proxy adds it to a request. Your Bots never see it. Each call gets a one-time token, and the key is removed from anything that comes back.
  • The same safety gate. Every action goes through Synapse's fixed rules and approvals, whatever the model. The safety reviewer runs on Claude when you've saved an Anthropic key, and otherwise on the provider you set up. You can pick another model for it in Settings → Auto-review → Safety reviewer. A reviewer on a model other than Claude asks you first until it passes the safety check.

Set up

  1. Create an API key on the OpenAI platform, with some credit on the account.
  2. In Synapse, open Settings → Account → Model providers. Click Allow next to OpenAI, read what it sends, and allow it.
  3. Paste the key, click Save, then Test key.
  4. Open a Bot's settings and pick an OpenAI model.

You can also start with OpenAI: pick it in the key step when you first open Synapse, allow it, and paste the key. It's tested before it's saved, and no Anthropic key is needed.
