Works with

Run your Bots on the AI provider you choose: your own key, a model on your Mac, or a coding plan you already have.

Your own key

  • Claude, with an Anthropic API key.
  • OpenAI, with an OpenAI API key.
  • OpenRouter, with an OpenRouter key.
  • Gemini, with a Gemini API key.
  • Mistral, with a Mistral API key.
  • DeepSeek, with a DeepSeek API key.

Setup takes any of these, or a model on your Mac. You don't need an Anthropic key unless you want Claude.

The provider bills your key. Synapse meters every call against your spend budget, and the model picker shows what a Bot would cost on each model.

On your Mac

  • Ollama and LM Studio. No key, no per-token cost.

Your coding plan

  • GitHub Copilot, Cursor, Kimi Code and Mistral Vibe, through their own CLIs. Experimental.

Not supported

  • Signing in with a Claude subscription or a Claude Code login.
  • Signing in with a Google account for the Gemini CLI or Antigravity.

How badges are earned

In the model picker, each model outside Claude has a badge. It comes from checks run on that model, never from a list we wrote.

BadgeMeans
Not checkedNothing measured yet. Every model starts here.
ExperimentalIt passed the must-pass provider checks, such as tool calls, streaming, usage reports, a bad key and stopping mid-reply.
SupportedIt also passed the coding benchmark, at 85% or more of Claude's pass rate on the same tasks, with every trap task passed.
BlockedIt failed a must-pass check or a trap task.
LocalIt runs on your Mac.

No model outside Claude is Supported yet. The coding CLIs are Experimental until a live check with a real sign-in passes.

Privacy

  • Consent first. Each provider is allowed once, before anything is sent to it. The consent says what goes there. A new version of the consent asks again.
  • Only where you choose. A Bot's conversation goes to the provider you picked for it, under that provider's terms. A Bot's own background work, like its memory notes and summaries, stays on its provider too. Synapse's shared work, like the safety reviewer and reading schedules, runs on Claude when you've saved an Anthropic key, and otherwise on the provider you set up. You can pick another model for the reviewer in Settings.
  • Keys stay on your Mac. They are encrypted and added only by Synapse's own proxy. Your Bots never see them.
  • The same safety gate. Every action goes through Synapse's fixed rules and approvals, whatever the model. The safety reviewer runs on Claude when you've saved an Anthropic key, and otherwise on the provider you set up. You can pick another model for it in Settings → Rules → Safety reviewer. A reviewer on a model other than Claude asks you first until it passes the safety check.
