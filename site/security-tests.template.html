Security tests

Attacks a Bot could face, and what Synapse does about each one. The tests run Synapse's real code with the AI reviewer swapped for one that approves everything, so every stop here comes from fixed rules, not a model's judgement.

Run them yourself

You need the source and Node 24. No API key, no model and no network.

git clone https://github.com/nyfeblade/synapse
cd synapse
npm ci
npm run security-suite

It prints a summary and writes a report to security/results/. Add -- --with-model to also run the approval eval's must-block cases through the real AI reviewer, if you have one set up. The README has the details.

What they don't cover

  • The AI reviewer's own judgement. These tests assume it is fooled every time; the optional model tier tests the reviewer itself.
  • The box firewall on a real kernel. The tests read the rules the box would load; the Bots' computer checks the loaded rules itself when it starts.
  • Anything a person approves. A card you accept runs.
