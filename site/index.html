What it does

A small team that does real work, not just chat.

Each Bot has its own memory, skills and a computer to work on, and asks before anything risky.

A team

Several Bots, each with its own name, memory, skills and computer. They hand work to each other as well as to you.

Real work

Multi-step tasks on their own Linux computer: files, the shell, the web and the accounts you connect.

Code

Point a Bot at a repository. It works on its own branch, runs the tests and hands back the branch or a pull request.

Voice calls

Call a Bot and talk. Speech is transcribed and the voice is generated right on your Mac.

Your Mac, with approval

Bots can use your apps and screen and run commands in a sandbox. Anything risky waits for your OK.

Spend you can see

Every model call is metered. See spend per Bot by day, week and month, and set budgets that pause or ask first.

Get started

Three steps, about ten minutes.

Most of that is the Bots' computer setting itself up. Full install guide →

Install

Install OrbStack, then download Synapse and drag it to Applications. The first time, open it with right-click → Open.

Privacy and security

Local by default. Nothing goes through us.

  • No account, no server. Synapse talks straight to Anthropic with your key. There is no Synapse cloud.
  • Sandboxed Bots. Bots work in their own Linux computer. On your Mac, commands run in a sandbox that can't read the app's own secrets.
  • Secrets sealed on your Mac. Your key and every other secret are encrypted with a key that never leaves the app's data folder.
  • Budgets checked first. A Bot pauses or asks you before spending past the limits you set.

Questions

Before you download

More in the docs.

What does it cost?

Synapse is free and open source under the MIT licence. You pay Anthropic for what your Bots use on your API key, and you can set spending budgets inside the app.

Why does macOS warn me the first time?

Synapse is signed with its own certificate rather than an Apple Developer ID, and isn't notarized by Apple yet. Open it once with right-click → Open, or click Open Anyway in System Settings → Privacy & Security. After that it opens normally.

What do I need?

A Mac with Apple silicon on macOS 14 or later, about 8 GB of free disk, OrbStack, and an Anthropic API key.

Can I use my Claude subscription instead of an API key?

No. Synapse uses an Anthropic API key only; signing in with a Claude subscription or Claude Code login isn't supported.

Is it finished?

It's a beta. It works, and it's been tested on a fresh Mac, but expect rough edges. Please open an issue if something breaks.
