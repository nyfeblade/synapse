Questions

What does it cost?

Synapse is free and open source under the MIT licence. You pay Anthropic for what your Bots use on your API key, and you can set budgets inside the app.

Why does macOS warn me the first time?

Synapse is signed with its own certificate rather than an Apple Developer ID, and isn't notarized by Apple yet. Open it once with right-click → Open, or click Open Anyway in System Settings → Privacy & Security. After that it opens normally.

What do I need?

A Mac with Apple silicon on macOS 14 or later, about 8 GB of free disk, OrbStack, and an Anthropic API key.

Can two people use it on one Mac?

Yes. Since 0.1.1, Synapse runs in two macOS accounts on the same Mac at once. Each account gets its own connection to its own Bots' computer.

Can I use my Claude subscription instead of an API key?

No. Synapse uses an Anthropic API key only; signing in with a Claude subscription or Claude Code login isn't supported.

Is it finished?

It's a beta. It works, and it's been tested on a fresh Mac, but expect rough edges. Please open an issue if something breaks.
